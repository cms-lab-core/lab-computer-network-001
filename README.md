# lab-computer-network-001

Первая лабораторная по компьютерным сетям: два Linux-хоста и два маршрутизатора FRRouting.

Рабочие файлы находятся в `task/`.

- `task.ipynb` — интерактивная статья и практика;
- `topology.template.yaml` — Clabernetes topology;
- `terminal.template.yaml` — terminal targets;
- `capture.template.yaml` — traffic capture;
- `topology.clab` — локальный Containerlab;
- `assets/` — схемы и анимации.
